# 画匣 · 图像工作室

公开的单文件 HTML 前端。文生图、多张参考图、常见画幅、独立任务计时、作品预览和下载。

打开网站，在「设置」填写自己的中转站 HTTPS 基础地址和 API Key，并同步模型。每位访客的模型、任务和作品保存在自己的浏览器；API Key 仅保留在当前页面内存，刷新或关闭后需要重新输入。

页面直接连接访客填写的中转站，中转站和图片服务需允许浏览器跨域访问（CORS）。同步任务需要保持页面打开；异步任务取得上游编号后，可在重新连接原中转站并输入原 Key 后查询原结果。未取得编号的断线请求不会自动重复提交，请先核对中转站记录。

参考图只有在点击生成后才发送到中转站。网页内没有公共 API Key，也没有服务器代理或共享生成额度。

GitHub Pages 从根目录的 `index.html` 发布。更新此文件即可更新网页；`.nojekyll` 保持原始 HTML 部署。
